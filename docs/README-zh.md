# Hardwhat
用于查看硬件信息的 WPF (.NET Framework) 应用程序
---
### [English](../README.md) | 简体中文

基于 .NET Framework，通过 **WMI** (Windows Management Instrumentation) 查询硬件信息。
采用 GPL-3.0 许可证（**侧边栏和窗口的图标除外**）。
